* Introduction

This is a literate Emacs configuration that provides a modern, powerful development environment optimized for Ruby on Rails and React Native development. It combines the flexibility of Emacs with modern IDE-like features and provides comprehensive documentation for every configuration decision.

** Overview

Performance-optimized modular Emacs configuration for Ruby/Rails and React Native development. Uses org-babel tangling to generate modular .el files from this documented source.

** Architecture

This configuration is organized into feature-based modules, each in its own `.org` file:

- =performance.org= - Performance & startup optimization
- =core.org= - Core settings and behavior
- =evil.org= - Vim emulation with Evil mode
- =completion.org= - Completion & search systems
- =navigation.org= - Navigation & buffer management
- =explorer.org= - File explorer & project dashboard
- =project.org= - Project management
- =workspace.org= - Workspace management
- =git.org= - Version control & Git integration
- =development.org= - Ruby/Rails + React Native/TypeScript development
- =ui.org= - User interface & themes
- =focus.org= - Focus mode for distraction-free editing

* Auto-tangling Configuration

#+begin_src emacs-lisp
;; Auto-tangle configuration for all org files in this directory
(defun je/auto-tangle-config-files ()
  "Auto-tangle all .org configuration files in the config directory."
  (interactive)
  (let ((config-dir (file-name-directory (or load-file-name buffer-file-name)))
        (org-files '("performance.org" "core.org" "evil.org" "completion.org"
                     "navigation.org" "explorer.org" "project.org" "workspace.org"
                     "git.org" "development.org" "ui.org" "focus.org")))
    (dolist (file org-files)
      (let ((full-path (expand-file-name file config-dir)))
        (when (file-exists-p full-path)
          (with-current-buffer (find-file-noselect full-path)
            (org-babel-tangle)
            (kill-buffer)))))))

;; Hook to auto-tangle when any config org file is saved
(defun je/setup-auto-tangle-hooks ()
  "Set up auto-tangle hooks for config files."
  (add-hook 'after-save-hook
            (lambda ()
              (when (and buffer-file-name
                         (string-match-p "/\\.config/emacs/.*\\.org$" buffer-file-name))
                (org-babel-tangle)))
            nil t))

;; Initialize auto-tangling
(add-hook 'org-mode-hook #'je/setup-auto-tangle-hooks)
#+end_src

* Module Loading

Load all configuration modules in the correct order:

#+begin_src emacs-lisp
;; Load configuration modules in dependency order
(let ((config-dir (file-name-directory (or load-file-name buffer-file-name))))
  (dolist (module '("modules/performance"
                    "modules/core"
                    "modules/evil"
                    "modules/completion"
                    "modules/navigation"
                    "modules/explorer"
                    "modules/project"
                    "modules/workspace"
                    "modules/git"
                    "modules/development"
                    "modules/ui"
                    "modules/focus"))
    (let ((module-path (expand-file-name (concat module ".el") config-dir)))
      (when (file-exists-p module-path)
        (load module-path)))))
#+end_src
