* Introduction

This configuration provides a modern, Vim-like experience through Evil mode with Spacemacs-inspired =SPC= leader bindings, combined with familiar VS Code-style Command key shortcuts for macOS users. The configuration is optimized for Ruby/Rails and React Native/TypeScript development.

** Key Design Principles
- =SPC= as leader key for all major operations (Spacemacs-style)
- =Cmd+Key= bindings for familiar VS Code-like navigation
- Evil mode for Vim-style editing with modern enhancements
- Consistent, discoverable key patterns with which-key integration

** Navigation Modes
- **Normal Mode**: Vim navigation and commands
- **Insert Mode**: Standard text insertion
- **Visual Mode**: Text selection and manipulation
- **Command Mode**: Ex-style commands with =:=

* Evil Mode Fundamentals

** Mode Indicators
Your modeline shows the current Evil mode:
- =<N>= Normal mode (default)
- =<I>= Insert mode
- =<V>= Visual mode

* Tips and Productivity

** Discovery and Learning
- **Which-Key Integration**: Start typing any key sequence and pause - a help window shows available completions
- **=C-h k {key}=**: Discover what any key does
- **=C-h b=**: See all current keybindings
- **=SPC c k=**: Show Command key reference

** Essential Patterns
- **=SPC=**: All major operations (files, buffers, search, etc.)
- **=C-c=**: Mode-specific and personal keybindings
- **=C-x=**: Core Emacs file and buffer operations
- **=Cmd+Key=**: VS Code-style shortcuts for quick actions

**** wgrep Workflow (Project Replace):
1. =SPC R p= → Enter search term → Results appear in grep buffer
2. =r= → Enter wgrep-mode (makes results editable)
3. Edit the results directly (use normal Emacs editing)
4. =C-c C-c= → Apply all changes to actual files
5. =C-c C-k= → Cancel changes if needed

*** Multi-Cursor Workflow Examples
**** Replace variable name across function:
1. Position cursor on variable name
2. =C-d= repeatedly to select all occurrences in view
3. =C-S-l= to select ALL occurrences in buffer
4. Type new name → all selected instances change simultaneously

**** Add content to multiple lines:
1. =C-v= (visual block) to select column
2. =I= to insert at beginning of each line
3. Type content → appears on all selected lines
4. =ESC= to finish

**** Project-wide rename:
1. =SPC R p= → Enter old name
2. =r= to enter wgrep-mode
3. =M-%= → Enter old name → new name → =!= (replace all)
4. =C-c C-c= to apply changes to all files
